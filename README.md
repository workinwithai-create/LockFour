# LockFour

Four-bar live lock desk for bedroom producers and AI-music finishers.

Straight or loose AI loops never lock. Session players add ghost notes, light accents, and tight hats so the pocket sits and the track finishes.

Live samples only — FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, violin, and acoustic kit from the PreEight sample CDN pinned to commit `d58301e4a494555f411a2afbc448b724136eee76`.

No oscillators.
Audio never leaves the tab.
